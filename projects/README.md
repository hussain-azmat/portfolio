# Project Articles

This folder stores the detailed case studies for the projects in the portfolio's Recent Works section.

## Structure

- `article-template.html` — reusable article structure and layout
- `article.css` — shared article styling
- Each project has its own HTML page, such as `indoor-asset-tracking.html`

## How to add/edit content

1. Open any project article page.
2. Update the title, subtitle, overview, technical details, journey, and gallery blocks.
3. Add or replace project images in the same folder or point to an image under `../assets/img/`.
4. Keep the section structure consistent for a professional, portfolio-like presentation.

## Recommended sections

- Overview
- Problem and context
- Design and architecture
- Development journey
- Technical decisions
- Results and outcomes
- Gallery / photos
- Lessons learned

## Theme

All article pages use the same visual language as the main portfolio: dark theme, premium accent colors, structured cards, and technical editorial styling.
